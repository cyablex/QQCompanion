# 游戏模式

控制台首页的“自动检测游戏”开关，或主人 QQ 指令 `/游戏模式 自动 开`、`/游戏模式 自动 关`，用于开启和关闭检测。新安装默认关闭，可在需要时开启。检测复用本项目的语音守护服务，不添加系统自启任务；该服务随大肥鱼启动，关闭控制台窗口不影响检测。

每 4 秒从 Windows 只读进程名单比对 `Endfield.exe`（终末地）和 `VALORANT-Win64-Shipping.exe`（无畏契约），忽略大小写。启动大肥鱼时游戏已运行也会生效。两款同时运行时，全部退出后恢复。

- `/游戏模式 开` 或控制台手动开启会立即暂停工作进程。自动检测开启时，识别到游戏后会随本轮游戏一起结束。
- `/游戏模式 关` 或控制台手动关闭可跳过当前游戏。两款游戏全部退出后，下次启动会重新检测。
- 关闭自动检测时，纯手动开启的模式可手动结束，已由游戏接管的模式会退出。

游戏模式暂停本地识别、GPT-SoVITS、唱歌制作与播放、桌宠，文字聊天和 QQ 连接继续工作。资源释放只针对由解释器、脚本路径或宿主路径识别出的本项目工作进程及其子进程。权限不足或结束超时会记录未释放的 PID，控制台和 `/状态` 可查看。检测失败时沿用上次状态。

游戏结束后保留原来的语音、识别、唱歌和桌宠偏好，桌宠仅在原开关开启时恢复。排队中的常规歌曲制作继续沿用原有恢复流程。合成服务等待下次实际语音请求再加载；准备期间先回文字，加载完成后可继续语音。独立歌曲试听若被中断，可在原入口重新制作。

命令行使用 `runtime/python.exe app/game_mode.py auto-on` 或 `auto-off` 控制自动检测，使用 `on` 或 `off` 手动切换。本地诊断文件 `data/game-mode-monitor.json` 在状态变化时更新，资源释放结果见 `data/game-mode-release.json`。
