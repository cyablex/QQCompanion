# 游戏模式

控制台首页的“自动检测游戏”开关，或主人 QQ 指令 `/游戏模式 自动 开`、`/游戏模式 自动 关`，用于开启和关闭检测。新安装默认关闭，可在需要时开启。检测复用本项目的语音守护服务，不添加系统自启任务；该服务随大肥鱼启动，关闭控制台窗口不影响检测。

每4秒按完整进程名检查 `Endfield.exe`（终末地）和 `VALORANT-Win64-Shipping.exe`（无畏契约），忽略大小写。启动大肥鱼时游戏已运行也会生效；两款同时运行时，要全部退出才结束自动游戏模式。

- `/游戏模式 开` 或控制台手动开启：持续保留，游戏结束不会替你关闭。
- `/游戏模式 关` 或控制台手动关闭：本轮游戏期间不再自动开启，直到两款游戏全部退出。下次游戏启动重新检测。
- 关闭自动检测：只撤销自动开启的状态，保留手动开启的状态。重新开启检测会重新判断正在运行的游戏。

游戏模式暂停本地识别、GPT-SoVITS、唱歌制作与播放、桌宠；文字聊天和 QQ 连接保留。只结束由解释器、脚本路径或宿主路径识别出的本项目工作进程及其子进程，不按 Python 进程名批量结束。权限不足或结束超时会记录未释放的 PID，并在控制台和 `/状态` 中显示；检测失败会保留上次状态。

游戏结束后保留原来的语音、识别、唱歌和桌宠偏好，桌宠仅在原开关开启时恢复。排队中的常规歌曲制作继续沿用原有恢复流程。合成服务等待下次实际语音请求再加载；准备期间先回文字，加载完成后可继续语音。独立歌曲试听若被中断，可在原入口重新制作。

命令行开关：`runtime/python.exe app/game_mode.py auto-on` / `auto-off`；手动模式为 `on` / `off`。本地诊断记录为 `data/game-mode-monitor.json` 和 `data/game-mode-release.json`。
