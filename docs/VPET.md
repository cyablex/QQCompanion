# VPet 桌宠首阶段

V5.4 起提供一个基于 [VPet-Simulator.Core](https://www.nuget.org/packages/VPet-Simulator.Core/1.1.0.72) 的小型 WPF 宿主。当前使用原作者的演示动作素材；角色外观尚未定制，已有 QQ 表情包不等于完整的 VPet 动作集。

## 准备与使用

先完成主项目的基本环境与账号设置，再运行 `准备桌宠环境.cmd`。它在本安装目录准备独立 .NET SDK、下载指定版本的基本动作素材并构建宿主；不会修改系统 .NET 安装，不会直接启用桌宠。

打开或重新打开控制台，进入“桌宠”页启用。可以摸头、点击身体、长按头部提起拖动；右键调整大小，打开共同经历、日历、曲库，或者退出。当前显示窗口为透明置顶窗口。

后台需运行。初次启动聊天后台时，桌宠会等待本机接口准备。原生宿主源码在 `integrations/vpet/`，后台接入在 `app/vpet_bridge.py`，进程管理在 `app/vpet_runtime.py`。

## 共用现有后台

触摸和提起在本机身份下进入原有 Engine，使用现有模型、人物设定、私聊历史、调用预算和发送校验。回应显示在桌宠气泡，QQ 不额外收到一份；后续私聊可以读取这些真实互动记录。

连续点击会继续播放动画，后台回应至少间隔30秒。状态轮询不调用模型。第一阶段只接受摸头、身体点击与提起这三种互动，不提供桌面自由聊天、点歌任务执行、语音口型或任意桌面控制。

接口绑定 `127.0.0.1:8766`，使用本安装生成的本机令牌，拒绝浏览器来源和由客户端指定主人身份。令牌与个人记录留在本机，不随源码导出。退出或遗忘不会自动重放旧互动。

## 游戏模式与资源

游戏模式退出本安装的宿主进程；结束后，若此前启用桌宠，则恢复。右键主动退出会关闭启用状态，守护不会重新拉起。停止整个后台也会关闭桌宠。

基础演示宿主约12 MiB、动作素材约13 MiB；不包括主项目、语音模型、缓存和开发环境。开发 SDK 约714 MiB，只有构建时使用，不等于桌宠常驻内存。原生窗口隔离演练中单次观察约190 MiB 内存；不同动作、缩放、系统和运行时长仍需实测，控制台会显示当前进程数值。

新的离线资源包包含已经准备的桌宠资源，恢复时不恢复本机令牌和自动启用状态。旧资源包缺少桌宠时仍能恢复其原有组件。
