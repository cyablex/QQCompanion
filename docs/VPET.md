# VPet 桌面陪伴

V5.4 起提供一个基于 [VPet-Simulator.Core](https://www.nuget.org/packages/VPet-Simulator.Core/1.1.0.72) 的小型 WPF 宿主。缺少本机角色素材时使用原作者的演示动作；V5.9可转换已有QQ表情，V5.10支持可选的本机高清姿态。

## 准备与使用

先完成主项目的基本环境与账号设置，再运行 `准备桌宠环境.cmd`。它在本安装目录准备独立 .NET SDK、下载指定版本的基本动作素材并构建宿主；不会修改系统 .NET 安装，不会直接启用桌宠。

打开或重新打开控制台，进入“桌宠”页启用。可以摸头、点击身体、长按头部提起拖动。右键选择“和大肥鱼说话”打开聊天窗口：Enter 发送，Shift+Enter 换行，每条最多2000字。还可以散步、安静陪伴、调整大小，打开共同经历、日历、曲库，或者退出。当前显示窗口为透明置顶窗口。

聊天窗口展示与 QQ 共用的近期文字记录。桌面收到的语音、歌曲可重播或停止，图片和表情可点开查看；附件控件保留本次窗口运行中最近20份，较早作品仍可从控制台画册、曲库找到。V5.9起GIF表情可动态播放，关闭或遗忘时释放播放器；语音口型尚未接入。

默认空闲时偶尔散步，可在右键菜单关闭。安静陪伴切换休息动作，暂停自动走动和自动播放，仍可聊天或手动播放；它不更改 QQ 的语音设置。托盘支持显示、隐藏、聊天、切换陪伴模式和退出。隐藏时暂停自动播放；位置、大小、安静与散步设置会保存在本机，重开时恢复并调整到可见范围。

后台需运行。初次启动聊天后台时，桌宠会等待本机接口准备。原生宿主源码在 `integrations/vpet/`，后台接入在 `app/vpet_bridge.py`，进程管理在 `app/vpet_runtime.py`。

## 共用现有后台

触摸和提起在本机身份下进入原有 Engine，使用现有模型、人物设定、私聊历史、调用预算和发送校验。回应显示在桌宠气泡，QQ 不额外收到一份；后续私聊可以读取这些真实互动记录。

V5.5 起，桌面文字聊天进入与 QQ 相同的持久待回复队列、Engine.reply 和真实动作执行模块。可以点歌、记录已有共同项目等，支持范围与现有聊天后台一致；普通承诺不会绕过参数、权限与执行结果核对。桌面发起的消息与异步歌曲回到桌面，QQ 发起的仍回 QQ，不因后来换入口而串发。

连续点击会继续播放动画，触摸互动的后台回应至少间隔30秒。状态、历史和输出队列轮询不调用模型。摸头、身体点击、提起及桌面文字进入共同记录；自动散步和安静动作属于本地显示设置，不冒充已经发生的模型活动。尚无麦克风输入、屏幕理解、语音口型或任意桌面控制。

接口绑定 `127.0.0.1:8766`，使用本安装生成的本机令牌，拒绝浏览器来源和由客户端指定主人身份或文件路径。附件只读取已经过原模块权限检查的实际文件。文字回复先持久排入桌面输出，再由窗口显示确认；“已接收/交给播放入口”不代表已经听完。请求重试不重做已登记任务，桌面来源信息丢失时也不会回落发到 QQ。

令牌与个人记录留在本机，不随源码导出。遗忘清理共同记录及桌面输出；窗口检测到遗忘后清空显示、附件和播放。播放临时文件在停止、完成或退出时清理，原始作品仍由现有曲库、语音与画册模块管理。窗口崩溃前未确认的消息可能再次显示，但不重新执行点歌等业务操作。

## 游戏模式与资源

游戏模式退出本安装的宿主进程；结束后，若此前启用桌宠，则恢复。右键主动退出会关闭启用状态，守护不会重新拉起。停止整个后台也会关闭桌宠。

宿主与动作素材的大小取决于已准备的动作集；V5.5 补充左右行走与休息动作。不包括主项目、语音模型、缓存和开发环境。开发 SDK 约714 MiB，只有构建时使用，不等于桌宠常驻内存。V5.4 原生窗口隔离演练中单次观察约190 MiB 内存；V5.5 增加聊天和附件后占用可能更高，控制台显示当前进程数值，不承诺固定内存。

新的离线资源包包含已经准备的桌宠资源，恢复时不恢复本机令牌和自动启用状态。旧资源包缺少桌宠时仍能恢复其原有组件。

## 资源来源

VPet Core 软件代码按上游 Apache-2.0 许可提供；演示角色动画适用上游单独的素材说明，见 [动画版权声明与授权](https://github.com/LorisYounger/VPet#动画版权声明与授权)。准备工具固定素材提交 `70263b91e3af9d68006b33c95ad63f59858ecbbe`，并保留来源文件；本仓库不附带下载后的动画或编译后的第三方二进制。

## V5.9 本机角色与状态

本机已有QQ女仆透明表情包时，可运行 `runtime/python.exe tools/prepare_pet_character.py`，或重新运行准备桌宠环境。它仅把已有本机素材转换为VPet动作，不调用模型、不更改桌宠开关。启用后优先使用本机蓝发女仆，缺少这些私人图片时继续使用上游演示素材。

已有待机、摸头、身体互动、提起、休息和移动的基础表现；移动复用开心轻跳，尚非完整专属行走或口型动作集。不要把本机图片和生成的角色包随公开源码上传。桌宠状态会区分绘图、主人点歌的后台阶段，以及本机正在播放的语音或歌曲。

## V5.10 缩放、日常与白米饭

右键菜单底部有50%—200%连续滑杆和恢复100%按钮。首次升级将之前实际大小作为100%基准，重启保留比例；不再局限于三档。

本机可选高清素材放在 `assets/pet/hq/`：`daily-sheet.png`、`walk-sheet.png`、`rest.png`。运行 `runtime/python.exe tools/prepare_pet_poses.py` 转成宿主姿态；总准备工具也会在有图时自动执行，不改变桌宠开关。当前工具按本版选定图集布局切分，不是任意角色图集的通用导入器。原图和生成角色包都属于私人资源，不附带在公开源码中；缺图时宿主继续用基础VPet角色。

自动日常小动作包括待机、看书、涂画与伸懒腰，右键也可手选；安静陪伴显示休息。它们是本地姿态与轻微呼吸/起伏，不是逐帧读书动画，也不表示已经真实读过文章或产出画作。真实绘图、点歌与播放状态仍显示实际任务。完整专属动作集与语音口型尚未接通。

右键“喂大白饭”放一碗可拖米饭；拿起后慢慢追来，追到后抱碗，保持按住可一起拖动，松手开吃；提前放下会追到再吃。一次只放一碗，可“收起米饭”。隐藏、遗忘、切换身份、退出或游戏模式会收起。安静陪伴下主动喂饭仍可玩，结束回到原设置。

固定的放饭、追到和吃完场景以真实来源存入共同记录，并显示在日历；不把鼠标坐标或每帧动作发给模型，不触发一轮新回答，也不更改正在处理的聊天标记。后续聊天与日记可读取这些背景，遗忘会一并清理。后台未就绪时可玩本地动作，但不补造未经确认的历史。

设计参考上游 [食物分层动画](https://github.com/LorisYounger/VPet/blob/main/VPet-Simulator.Core/Graph/FoodAnimation.cs) 与 [插件示例](https://github.com/LorisYounger/VPet.Plugin.Demo)。本实现使用自己的场景状态，与现有同一个后台联动，没有接入第二套聊天模型。
