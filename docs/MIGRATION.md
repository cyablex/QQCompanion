# 私人备份与新电脑恢复

## 三部分材料

1. 本仓库源码或经过检查的恢复工具夹。
2. 加密私人存档 `.dfysave`：聊天、记忆、人设、设置、作品与曲库。
3. 可选加密离线资源 `.dfyresources`：运行环境、模型、框架与前端构建文件。

恢复口令与备份包分开保管。忘记口令将无法解密；不要把口令写进仓库或脚本。
本工具使用 Scrypt 派生密钥和 AES-256-GCM 流式认证加密。只有完整验证认证标签后才安装存档文件。

## 导出

运行 `导出私人存档.cmd`，输入至少12字符的恢复口令和新的备份文件路径。
若后台正在写入，工具会拒绝这次不一致的快照；短暂停止聊天后台后再导出，并恢复原运行状态。

```powershell
runtime/python.exe -X utf8 app/migration.py resources-export --archive X:/backup/大肥鱼.dfyresources
```

离线资源包使用同一口令较便于配套恢复。资源包包含当前已安装的组件，不包含 QQ 程序、QQ 登录会话或 API Key；官方 QQ、显卡驱动和系统 WebView2 需要在新电脑准备。

## 恢复

将备份和恢复工具夹从 U 盘复制到新电脑本地磁盘。运行 `恢复大肥鱼.cmd`，分别选择存档、资源包与全新目标目录。
请选择一套新的相邻目录，避免与已有的 GPTSoVITS、SeedVC 或桌面环境重叠。离线资源恢复需要目标盘和临时盘各有与资源包相当的可用空间；若二者在同一盘，需要约两倍空间。
目标可以有源码，但不能有旧的 config/data/assets；运行资源目录也不能与已有安装重叠。
已存在的安装和备份文件不会被覆盖。资源阶段失败时，存档仍保持离线；可在解决原因后单独运行 `app/migration.py resources-restore --root 目标目录 --archive 资源包` 接续资源恢复。

工具修复画册、曲库和参考音色中登记的文件路径，重定向桌面与唱歌 venv 的基础解释器。
已发送与结果不明的回执保留；旧排队消息、待点歌、评论授权和跟进不会直接重放。

```powershell
runtime/python.exe tools/doctor.py --deep
```

核对画册、歌曲与记忆后，运行设置服务，重新保存 API Key。停止旧电脑的大肥鱼，显式运行启用命令，再按正常流程登录 QQ。

目录更换与同机隔离恢复可以由本工具验证；更换显卡或系统后还需实机确认语音和歌声模型兼容性。
平时更新存档即可；程序或环境升级后保留与存档配套的版本与资源包。
