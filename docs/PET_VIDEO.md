# 连续透明视频桌宠

V5.14 在原有WPF宿主中增加透明WebM视频播放。保留原来的聊天、任务、缩放、喂饭、潜水收起、安静与游戏模式，不安装第二套模型或Agent。

## 动作和形象

当前选取同一套蓝发鲸鱼娘女仆的14段连续动画，覆盖呼吸、哼歌、张望、慢走、提起、触摸反馈、挥手、伸懒腰、读写陪伴、白米饭、休息、哈欠与行礼。它们不是根据聊天实时生成的视频，也没有语音口型。读写日常只是陪伴动作，真实日记状态继续来自原后台。

常态动作尽量播放到片段边界再切换；触摸、提起、喂饭及实际任务可打断。摸头反馈在候选中轮换，避免紧接着重复。同一播放模式的静态预览与小头像也取自这套素材，不混用旧生成画风。解码失败停留在同一角色的预览图并提示，不反复重启失败的片段。

原视频为640×360、24帧/秒，选中片段统一使用中间360×360透明显示区域，脚底基准一致；排除了动作越出该区域的候选。提起动作仅循环悬空段，避免拎着时突然站回地面。高倍放大仍受原素材分辨率限制。

## 准备

先关闭桌宠，再运行：

```powershell
runtime/python.exe -X utf8 tools/prepare_pet_video.py
```

需要支持`libvpx-vp9`透明解码的FFmpeg。工具优先复用本机已有组件，也可用`--ffmpeg "完整路径"`指定。它只准备动作，不启用桌宠；没有可用解码器时会说明原因。

新安装也可运行`tools/prepare_vpet.py --video`，同时构建宿主并准备动作。仅复制新的素材到旧版宿主不会启用视频播放，需要使用包含V5.14播放器的宿主。

动作位于`vpet/characters/dafeiyu-v1/video/`，有`pack.json`、`decoder.json`、视频、预览和许可说明。本机组件路径尽量相对主程序记录，整体迁移后可继续解析；外置自定义FFmpeg迁移后可能需重新指定。公开源码不附带视频和FFmpeg二进制，工具从固定上游版本下载所需资源。

## 播放与资源

FFmpeg单线程流式解码，通过有界缓冲更新WPF图片；不把所有视频解压成常驻帧，不逐帧调用聊天模型，也没有声音自动播放。一次只保留当前解码器和切换画面。减少动效使用同源静态图；隐藏、最小化、退出和游戏模式会停止解码，宿主意外退出时也通过Windows作业对象清理其子进程。

运行素材约9MB，具体以实际文件为准，不包含已有FFmpeg及开发环境。帧率、CPU和内存需要结合机器、动作与窗口状态实测，源码构建通过不等同于动画在目标机器上达到24帧/秒。
