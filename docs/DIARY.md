# 鲸鱼日记

控制台的“大肥鱼日历”默认打开日记本，也可切回按日期查看的日历。

日记本按月整理已经写下的长日记和真实共同经历。可翻页、搜索、夹书签、筛选纪念页及调整字号；没有写过日记的日期只显示已有记录，不补造正文。歌曲、画作和完成项目会保留对应入口，可接着试听或查看。旧项目没有明确完成时间时，不把最后修改时间当作完成纪念日。

“本月封面”与每页的“换一幅插画”可选择主题图，也可从当前主人的画册或公开作品中选择；封面按月保存，插画按日期保存。删除的作品自动回到主题插画。私人角色图片不附带在公开源码里，缺图时使用简洁装饰。

“请她写今天”沿用原有日记的真实材料、限额与生成流程。她实际生成时显示写作状态；只有正文保存成功才显示完成，没有新材料则保留已有日记。写作中断不会永远显示“正在写”。桌宠开启时会配合写字动作，完成提示可进入对应日期。

日常看书和涂画动作是陪伴表现，不代表实际读过文章或创作了新作品。写作状态和纪念页以后台真实记录为准。

轻音效默认关闭，开启后也遵守安静模式；页面支持系统减少动效偏好。书签、封面和插画选择随主人的记录隔离，遗忘会清除对应数据和正在显示的旧内容。
